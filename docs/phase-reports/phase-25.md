# تقرير المرحلة 25 — تعدد الشركات للمستأجر

**المرجع:** [ADR-040](../decisions/ADR-040-phase25-multi-company.md). نقطة البيع مستثناة من النظام بقرار المالك (2026-11-20).

## 1. ما أُنجز

- **الشركة لكل طلب:** `CompanyGuard` يقرأ `X-Company-Id` ويتحقق أنها شركة نشطة في المستأجر ومسموحة للعضو، ثم يضعها في CLS. بدون الترويسة تُستخدم أول شركة مسموحة، فلا يتغير شيء للمستأجرين الحاليين.
- **الخدمات:** 21 موضعاً كانت تختار "أول شركة نشطة" صارت تقرأ شركة الطلب (`currentCompanyFilter`). `BranchGuard` وقائمة الفروع و`/me` تعرض فروع الشركة الحالية فقط.
- **صلاحية العضو:** جدول `membership_companies`. لا صفوف تعني كل الشركات، والمالك يرى كل الشركات دائماً.
- **إدارة الشركات:** `GET|POST /companies` و`PATCH /companies/:id` للمالك. الشركة الجديدة بدليل حسابات وربط حسابات وفرع رئيسي، ولا تُوقف آخر شركة نشطة.
- **الواجهة:** قائمة الشركة في الشريط العلوي (تظهر مع شركتين فأكثر)، وتبويب "الشركات" في الإعدادات، وعمود "الشركات المسموحة" في صفحة المستخدمين.

## 2. الجداول

- جديد: `membership_companies` (migration `20261120153834_phase25_multi_company`). لا تغيير على الجداول المالية.

## 3. الاختبارات

- `golden-multi-company.e2e.spec.ts`: C1–C3 (5 اختبارات).
- `isolation-sweep.e2e.spec.ts`: يشمل `PATCH /companies/{id}`.
- اختبارات الواجهة 825، وtypecheck وlint للـ API والواجهة.

## 4. مؤجل

- التقارير الموحدة لعدة شركات، والمعاملات بين الشركات، وحد عدد الشركات حسب الخطة.
