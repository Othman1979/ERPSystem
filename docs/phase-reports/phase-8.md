# تقرير المرحلة 8 — التقارير والطباعة

**التاريخ:** 2026-11-10
**الفرع:** `phase-8-reports` (فوق `phase-7-jofotara` ← `phase-6-open-items`)
**الحالة:** منجزة ومختبرة. لا migrations. القرارات في [ADR-006](../decisions/ADR-006-printing-phase8.md).

## 1. ما تم إنجازه مقابل المخرجات

| المخرَج | الحالة |
|---|---|
| كل تقارير §15 بصيغ JSON وPDF وXLSX | ✅ `?format=json\|pdf\|xlsx&lang=ar\|en` على ميزان المراجعة، الأستاذ، كشف الحساب، أعمار الديون، أرصدة المخزون، تقييمه، حركة الصنف، والتقارير الجديدة |
| قائمة الدخل | ✅ شجرة الحسابات بمجاميع فرعية؛ تكلفة المبيعات = تكلفة البضاعة + فروقات المخزون؛ مجمل الربح وصافيه |
| الميزانية العمومية بربح السنة الديناميكي | ✅ الأصول = الخصوم + حقوق الملكية + أرباح السنوات السابقة + ربح السنة (لا قيود إقفال بعد) |
| ملخص الضريبة | ✅ لكل (فئة، نسبة، رمز الفوترة): الأساس والضريبة للمخرجات (المبيعات − مرتجعاتها) والمدخلات، المستحق، والفرق عن حسابات الضريبة (يجب أن يكون 0) |
| ملخص المبيعات والمشتريات | ✅ حسب اليوم/الشهر/الطرف/الصنف؛ المبيعات مع التكلفة والهامش |
| قوالب الطباعة (§13.7) | ✅ فاتورة البيع، المرتجع، فاتورة الشراء، سند القبض، سند الصرف (PDF A4)؛ كشف الحساب عبر `party-statement?format=pdf` |
| لوحة تحكم مختصرة | ✅ مبيعات اليوم والشهر، الذمم (الإجمالي والمتأخر)، الأصناف تحت الحد الأدنى |

## 2. الجداول والـ migrations
- لا جداول ولا migrations جديدة. لم يحتج اختبار الأداء فهارس إضافية.
- متغيرات جديدة: `REPORT_PDF_MAX_ROWS` (1000)، `REPORT_XLSX_MAX_ROWS` (50000).
- تبعيات جديدة (بموافقة المالك، بالإصدار): `pdfmake` 0.3.14، `exceljs` 4.4.0، `bidi-js` 1.1.0،
  `fontkit` 2.0.4؛ الخط IBM Plex Sans Arabic (OFL) في `apps/api/assets/fonts`.

## 3. الـ endpoints والشاشات
| الطريقة | المسار | الوظيفة |
|---|---|---|
| GET | `/reports/income-statement?from&to` | قائمة الدخل (الافتراضي: السنة المالية الحالية) |
| GET | `/reports/balance-sheet?asOf` | الميزانية العمومية |
| GET | `/reports/tax-summary?from&to` | ملخص الضريبة |
| GET | `/reports/sales-summary?from&to&groupBy` / `/reports/purchases-summary?…` | ملخص المبيعات / المشتريات |
| GET | `/dashboard/summary?date=` | لوحة التحكم |
| GET | `/sales-invoices/:id/pdf`، `/sales-returns/:id/pdf`، `/purchase-invoices/:id/pdf`، `/receipts/:id/pdf`، `/payments/:id/pdf` | المستندات المطبوعة |

إصلاحات في التقارير القائمة: الرصيد الافتتاحي للأستاذ وكشف الحساب يُجمع في قاعدة البيانات؛ قيمة المخزون
الإجمالية = Σ `item_costs.total_value`؛ أرصدة المخزون وحركة الصنف بلا حد صامت (كانت 1000 و2000 صف)
و413 فوق حد التصدير؛ "تحت الحد الأدنى" يقارن مجموع الصنف في كل المستودعات؛ حركة الصنف برصيد افتتاحي.

الشاشات:
- **التقارير:** تبويبات جديدة — قائمة الدخل، الميزانية العمومية (شارة متوازن/غير متوازن)، ملخص ضريبة
  المبيعات (اختيار فترة شهرين كما في إقرارات الضريبة الأردنية، وشارة حمراء إن اختلف عن حسابات الضريبة)،
  ملخص المبيعات وملخص المشتريات (تجميع حسب اليوم/الشهر/الطرف/الصنف). زرا **PDF** و**Excel** على كل
  تقرير (وأرصدة المخزون وتقييمه وحركة الصنف)، مع رسالة مفهومة عند تجاوز الحد.
- **الرئيسية:** أربع بطاقات فوق الإجراءات السريعة — مبيعات اليوم، مبيعات الشهر، ذمم العملاء (والمتأخر)،
  الأصناف تحت الحد الأدنى؛ كل بطاقة تفتح تقريرها.
- **الطباعة:** زر "طباعة" في فاتورة البيع والمرتجع وفاتورة الشراء وسند القبض والصرف يفتح PDF الخادم
  (بلغة الواجهة). مرتجع الشراء ما زال يطبع الشاشة (لا قالب له بعد).

تحقق في المتصفح على `erp_dev`: لوحة التحكم (مبيعات اليوم 10.000، الذمم −92.000 والمتأخر 1,068.000 —
تطابق تقرير الأعمار)، قائمة الدخل تطابق ميزان المراجعة، الميزانية متوازنة وربح السنة = صافي قائمة الدخل
(−71.333)، ملخص الضريبة يبيّن فرق 480.000 عن حساب ضريبة المبيعات (ضريبة في بيانات العرض أُدخلت بقيود
يدوية لا بفواتير — تنبيه صحيح)، وPDF قائمة الدخل وفاتورة البيع (مع QR) من الـ API الحقيقي. **لم يُفحص:**
تنزيل الملفات من الأزرار داخل المتصفح المدمج (يعرض حوار حفظ)، وطباعة سندات القبض والصرف من الواجهة.

### 4.1 الأداء — 50,000 قيد / 100,000 سطر (مستأجر آخر 1,000 سطر)
| التقرير | الزمن | الحد |
|---|---|---|
| ميزان المراجعة JSON | 770 ms | 2 s |
| قائمة الدخل JSON | 698 ms | 2 s |
| الميزانية JSON (متوازنة) | 820 ms | 2 s |
| أستاذ الحساب الأكثر حركة JSON (17,597 سطراً) | 898 ms | 2 s |
| نفس الأستاذ XLSX | 1,520 ms | 15 s |
| ميزان المراجعة PDF | 2,011 ms | 10 s |

ميزان المراجعة طابق كل حساب بالفلس مقابل المجاميع المحسوبة في الاختبار، ولم يدخل فيه مستأجر آخر.
البيانات أُدخلت بـ SQL مباشرة (بموافقة المالك، لهذا الاختبار فقط).

المجموع: `pnpm --filter api test` — **25 ملفاً / 228 اختباراً** خضراء (ملف الأداء متخطى افتراضياً، 5 اختبارات).

## 5. أوامر التشغيل والنشر
- لا migrations. `pnpm install` (تبعيات جديدة)، ثم `pnpm --filter api build` (الخطوط في `apps/api/assets`
  تُقرأ من موقعها بجانب `dist`).
- اختبار الأداء: `RUN_PERF=1 pnpm --filter api test -- test/e2e/reports-perf.e2e.spec.ts` (يكتب 100k صف في `erp_test`).

## 6. المشاكل المعروفة والديون التقنية
- **مجمل الربح** يطرح فروقات المخزون (5102) ضمن تكلفة المبيعات (توصية المرحلة المعتمدة)؛ إن أراد المحاسب
  تكلفة البضاعة فقط فهو سطر واحد في `reports/statements.ts`.
- 4102/4103 بقيا بطبيعة رصيد دائنة في الشجرة (§8.7 يقول مدينة)؛ القوائم تحسب الإيراد Cr−Dr فتظهر المردودات
  سالبة بشكل صحيح. التعديل يحتاج قرار المحاسب وADR.
- تكلفة سطر مرتجع البيع غير محفوظة على السطر (على الرأس فقط)؛ ملخص المبيعات حسب الصنف يعيد حسابها
  بنفس طريقة الترحيل.
- لا فلتر فرع في التقارير (كل التقارير على مستوى الشركة)؛ لا شعار في المطبوعات (تخزين الملفات في المرحلة 9)؛
  لا مبلغ بالحروف ولا إيصال حراري 80mm.
- pdfmake لا يدعم الاتجاه الثنائي؛ طبقتنا (`rtl-text.ts`) تغطي الحالات المختبرة، والحالات النادرة
  (رموز مختلطة مثل `INV-1/أ`) قد تحتاج ضبطاً.
- `packages/api-client` لم يُعد توليده للـ endpoints الجديدة (الواجهة تستخدم `apiFetchData` مباشرة).

## 6.1 مراجعة مستقلة (2026-11-10) — ما أُصلح
- الأرقام الهندية (١٢٣) كانت تُطبع معكوسة؛ أُصلح مع اختبار يمر عبر fontkit.
- تصدير XLSX كان يفشل (500) إذا احتوى رمز صنف/طرف على `* ? :  / [ ]` (اسم الورقة)؛ يُنظَّف الآن.
- الهاتف والرقم الضريبي في ترويسة المطبوعات يبقيان كتلة واحدة من اليسار لليمين.
- حدود التصدير تُقرأ عند كل طلب (كانت تُقرأ قبل تحميل `.env`)، وخُفّضت إلى 1,000 / 50,000 (انظر ADR-006).
- مسافة التدرج في شجرة الحسابات تظهر في XLSX؛ أطوال الكلمات تُخزَّن مؤقتاً أثناء تقسيم الأسطر.

**مؤجل (لم يُطلب الآن):** عدد "تحت الحد الأدنى" في لوحة التحكم قد يختلف عن قائمة المخزون التي يفتحها
(القائمة صف لكل مستودع ولا تشمل الأصناف بلا حركة)؛ شريط "معكوس" في سند مطبوع يعرض وقت إدخال العكس لا
تاريخ قيده؛ تاريخ بأرقام هندية (٢٠٢٥-١٢-٣١) قد يُعاد ترتيبه؛ XLSX متدفق وPDF في worker.
